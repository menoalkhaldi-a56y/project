# تطبيق أوان — جاهز للنشر على GitHub Pages

## الملفات
- `index.html`: التطبيق.
- `manifest.json`: بيانات تثبيت التطبيق على الجوال.
- `service-worker.js`: دعم التخزين المؤقت والعمل دون اتصال بعد أول زيارة.
- `icon.svg`: أيقونة التطبيق.

## طريقة النشر
1. سجّلي الدخول إلى GitHub وأنشئي مستودعًا جديدًا باسم إنجليزي مثل `awan-app`.
2. اجعلي المستودع `Public`.
3. ارفعي **محتويات هذا المجلد** إلى المستودع، وليس ملف ZIP نفسه فقط.
4. تأكدي أن `index.html` موجود في جذر المستودع.
5. افتحي `Settings` ثم `Pages`.
6. في `Build and deployment` اختاري `Deploy from a branch`.
7. اختاري الفرع `main` والمجلد `/ (root)` ثم اضغطي `Save`.
8. انتظري دقيقة أو دقيقتين، وسيظهر رابط الموقع في صفحة `Pages`.

بعد فتح الرابط من الجوال، يمكنك اختيار «إضافة إلى الشاشة الرئيسية» إذا كان المتصفح يدعم ذلك.

ملاحظة: نموذج تسجيل الحساب في التطبيق تجريبي ومحلي، وليس نظام حسابات حقيقيًا. كما أن بعض وظائف الباركود وقراءة التاريخ موضحة داخل التطبيق على أنها محاكاة.
